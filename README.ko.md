# 조연당 온라인 · 제안함

[![English](https://img.shields.io/badge/lang-English-134538)](README.md)
[![한국어](https://img.shields.io/badge/lang-한국어-E985A2)](README.ko.md)

**[조연당 온라인](https://joyeondang.cmdspace.work)**에 대한 아이디어, 의견, 이벤트 제안을 받는 곳이에요. 조연당 온라인은 초대받은 손님이 아늑한 3D 집을 걷고, 방에 들어가 짧은 놀이를 하고, 그 집에 사는 가족에게 쪽지를 남기는 작은 온라인 집이에요.

이 저장소에는 **소스 코드가 없어요.** 방, 놀이, 이벤트, 캐릭터 꾸미기, 접근성, 버그에 대한 제안을 받는 창구예요.

## 이런 걸 제안할 수 있어요

| 갈래 | 예 |
|---|---|
| 방 | 방의 주제, 소품, 아늑한 디테일, 문 뒤의 작은 깜짝 놀이 |
| 놀이 | 아이와 어른이 함께 할 수 있는 짧고(2분 안팎) 다정한 놀이 |
| 이벤트 | 계절이나 기념일에 집에서 열리는 일: 장식, 작은 퀘스트, 도장 |
| 캐릭터 | 꾸미기 패널에 넣을 머리 모양, 옷, 소품 |
| 접근성·휴대폰 | 보기, 읽기, 누르기 어려운 곳 |
| 버그 | 고장 난 곳(기기와 브라우저를 함께) |

## 제안하는 법

1. 먼저 [열린 이슈](../../issues)를 찾아 봐요. 같은 생각이 있으면 👍를 눌러 주세요.
2. 새 이슈를 양식으로 열어요: **기능 제안**, **방·이벤트 아이디어**, **버그**.
3. 열린 생각이나 질문은 [토론(Discussions)](../../discussions)에 남겨 주세요.

무엇을 만들지는 그 집에 사는 가족이 정하고, 만드는 일은 CMDSPACE가 해요. 지금은 코드 기여는 받지 않고 아이디어만 받아요.

## 올리지 말아 주세요

- 가족이나 아이들의 실명
- 집 주소, 동네, 위치를 알 수 있는 것
- 집 사진, 아이 사진, 보이기로 동의하지 않은 사람의 사진
- 누구의 개인정보든(전화번호, 이메일, 계정)

보안·개인정보 문제를 찾았다면 공개 이슈로 올리지 말고 **Security → Report a vulnerability**로 비공개로 알려 주세요([SECURITY.md](SECURITY.md)).
